# 🌱 Plant Counter

An interactive Plant Growth Counter built with React. The plant grows as the counter increases and blooms when it reaches its maximum growth level.

## Features

- Increment and decrement counter
- Maximum count limit of 15
- Dynamic plant scaling based on count
- Flower blooms when the count reaches 15
- Dynamic growth captions based on the current count
- Browser tab title updates with the counter value

## React Concepts Practiced

- Functional Components
- `useState` Hook
- `useEffect` Hook
- Event Handling
- Conditional Rendering
- Conditional CSS Classes
- Dynamic Inline Styling
- JavaScript Ternary Operator
- Derived Values

## Technologies Used

- React
- JavaScript
- CSS
- Vite

## Learning Objective

To understand React state management, side effects, conditional rendering, and dynamic UI updates through a small interactive project.
