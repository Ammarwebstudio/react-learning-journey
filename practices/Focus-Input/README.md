# 🎯 Focus Input

A simple React practice project demonstrating how to use the `useRef` Hook to directly access and interact with DOM elements.

## Features

- Input field with a placeholder
- Button to automatically focus the input field
- Input focus management using React refs
- Focus status tracking

## React Concepts Practiced

- Functional Components
- `useRef` Hook
- DOM Element References
- The `.current` Property
- DOM Manipulation
- Event Handling
- `focus()` Method

## Technologies Used

- React
- JavaScript
- CSS
- Vite

## Learning Objective

To understand how `useRef` stores references to DOM elements and allows direct interaction with them without requiring a state update.
