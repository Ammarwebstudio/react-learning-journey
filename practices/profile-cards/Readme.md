# Profile Cards — React Practice

## Overview
A responsive Profile Cards section built with React to practice reusable components, props, and state management.

## Features
- Reusable `Profile` component
- Dynamic profile information using props
- Profile images passed through props
- Follow / Following button toggle using `useState()`
- Independent state for each profile card
- Custom styling with CSS

## Concepts Practiced
- React Functional Components
- Props and Component Reusability
- JSX
- Rendering Dynamic Data
- `useState()` Hook
- Event Handling with `onClick`
- Conditional State Updates
- CSS Styling

## Tech Stack
- React
- JavaScript
- CSS
- Vite

## Learning Outcome
Learned how to create reusable profile cards, pass dynamic data through props, and manage independent state for interactive Follow buttons.

## How to Run Locally
1. Install dependencies:
   ```bash
   npm install
   ```
2. Start the development server:
   ```bash
   npm run dev
   ```
