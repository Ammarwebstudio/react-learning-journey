# Hooks & State in React

## 🎯 What I Learned

### 1. Hooks
- Hooks allow functional components to use React features.
- React provides built-in Hooks for managing state and other functionality.
- Hooks are called at the top level of React components or custom Hooks.

### 2. State
- State is data that a React component can remember and update over time.
- When state changes, React can re-render the component to reflect the updated data.
- State helps create interactive and dynamic user interfaces.

### 3. useState Hook
- `useState` is a React Hook used to add state to functional components.
- It returns the current state value and a setter function.
- The setter function is used to update state.
