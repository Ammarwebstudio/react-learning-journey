# Components, Props and JSX in React

## 🎯 What I Learned

### 1. Components

- Components are reusable building blocks of a React UI.
- They help organize code into smaller, manageable pieces.
- React components are commonly written as JavaScript functions.
- Component names start with a capital letter.

### 2. JSX

- JSX stands for JavaScript XML.
- It allows us to write HTML-like syntax inside JavaScript.
- JavaScript expressions can be used inside JSX with curly braces `{}`.
- In JSX, we use `className` instead of `class`.

### 3. Props

- Props allow us to pass data from a parent component to a child component.
- They help reuse the same component with different data.
- Props should be treated as read-only.
