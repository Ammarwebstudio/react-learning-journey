# The useEffect Hook in React

## 🧠 Topics Covered

- Introduction to the `useEffect` Hook
- Understanding side effects in React
- Running an effect after every render
- Running an effect only on the initial mount using an empty dependency array (`[]`)
- Running an effect when specific dependencies change
- Using multiple `useEffect` Hooks in a component
- Understanding state and props changes
- React Strict Mode and its behavior during development
- Cleanup functions and component unmounting

## 💻 Tech Stack

- React
- JavaScript
- Vite

## 🎯 Learning Goal

To understand how the `useEffect` Hook works, how dependency arrays control effect execution, and how cleanup functions help manage side effects.
