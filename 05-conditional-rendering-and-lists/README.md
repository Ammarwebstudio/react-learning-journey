# Conditional Rendering & Rendering Lists in React

## 🧠 Topics Covered

- Conditional Rendering in React
- Using If-Else Conditions
- Ternary Operator (`? :`)
- Logical AND (`&&`) Operator
- Rendering Lists using `map()`

- Dynamically Rendering Data

## 💻 Tech Stack

- React.js
- JavaScript
- Vite

Learned how to conditionally render UI elements based on different conditions and dynamically display lists of data using the `map()` method in React. Also understood the importance of keys when rendering lists.
